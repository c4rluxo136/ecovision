# EcoVision

## Objetivo do Projeto

O projeto EcoVision foi desenvolvido para conscientizar as pessoas sobre a importância da preservação ambiental através de um portfólio fotográfico.

O site apresenta imagens relacionadas à natureza e sustentabilidade, buscando proporcionar uma experiência visual agradável e intuitiva.

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome

---

## Decisões de Design (IHC)

Para melhorar a experiência do usuário, foram utilizadas:

- Cores verdes e tons naturais para representar o meio ambiente
- Layout simples e intuitivo
- Design responsivo para celular e computador
- Efeitos visuais suaves
- Navegação simples e objetiva
